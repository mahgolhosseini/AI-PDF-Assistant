
# AI PDF Assistant 📄🤖

## 📝 Project Description

A web-based AI application that allows users to upload PDF documents, ask questions about their content, generate document summaries, and identify the main topic of the uploaded document. Built with HTML, CSS, and JavaScript, the application uses PDF.js to extract text from PDF files and Google Gemini API to provide AI-powered answers and summaries. Users can also download the generated summary as a PDF file.

## 🚀 Features

- Upload and read PDF documents
- Extract text from PDF files
- Ask questions about the uploaded document
- Generate a summary of the document
- Identify the main topic of the document
- Display AI-generated answers in a chat interface
- Download the generated summary as a PDF
- Responsive and user-friendly interface

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- PDF.js for PDF text extraction
- Google Gemini API for AI-powered responses
- Fetch API for API communication
- jsPDF for generating downloadable PDF summaries
